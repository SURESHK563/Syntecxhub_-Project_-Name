# 📰 Web Scraper for News Headlines

A Python-based web scraping project that collects the latest **news headlines** from multiple websites using **Requests** and **BeautifulSoup**.  
The scraper extracts **title, URL, and published time (if available)** and saves the results in both **CSV** and **JSON** formats.

This project is completed as part of the **Synctcxhub Internship Program**.

---

## 🚀 Features

- 🔍 Fetch headlines from multiple news sources  
- 📝 Extract title, URL, and timestamp  
- 🔑 Optional keyword filtering  
- 🌐 Supports multiple websites (BBC, NDTV, Hindustan Times, etc.)  
- 💾 Save results to CSV and JSON  
- 🛡 Respects robots.txt policies  
- 💤 Adds delay between requests to avoid server overload  
- ⚠️ Error handling for network and parsing issues
